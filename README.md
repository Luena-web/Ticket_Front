#APPLICATION DE GESTION DE TACHES / TASKMANAGEMENT

## Description 
Cette application permettra aux utilisateurs de pouvoir gérer leurs tâches . Ils peuvent créer une nouvelle tâche, la modifier ,la supprimer et la consultater.
### Technologies utilisées

1- React :  Pour la création de l'interface utilisateur.

2-TypeScript : Pour le typage des données et détection de certaines erreurs.

3-Vite :  Pour le lancement du serveur de développement et la construction du projet.

4-Axios : Pour assurer communication HTTP avec l'API REST(C'est une librairie).

5-React Router :  Pour assurer la navigation entre les pages.

6-Tailwind CSS :  Pour mise en forme de l'interface.

7-Laravel : Pour concevoir l'API REST.

8-MySQL :  Pour le stockage des données.

#### Prérequis 

Avant de lancer le projet, il faut  installé :

1- Installer `Node.js `

L'API Laravel de gestion des tâches, démarrée et accessible via :

`1- Cloner le projet`
`git clone https://github.com/Luena-web/API_Connect_React`

2- `Accéder au dossier du projet`

cd API_Connect_React

`3-Installer les dépendances`
npm install
Cette commande installe les bibliothèques nécessaires au fonctionnement du projet.

`4-Configurer l'API`
Vérifie que l'URL de ton API Laravel est correctement configurée dans ton projet React, notamment dans ton instance Axios.

`5- Démarrer l'application`
npm run dev
Ouvre ensuite dans ton navigateur l'adresse locale affichée dans le terminal.
